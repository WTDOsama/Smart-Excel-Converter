# محول Excel الذكي — Smart Excel Converter

تطبيق ويب احترافي عربي أولاً (RTL) لتحويل ملفات Excel إلى الفورمات المطلوبة باستخدام المطابقة الذكية للأعمدة.

## البنية التقنية

| الطبقة | التقنية | المجلد |
|---|---|---|
| الواجهة | React 18 + TypeScript + Tailwind CSS (RTL بالكامل، خط Tajawal) | `frontend/` |
| الخادم | Python + FastAPI + Uvicorn | `backend/` |
| معالجة Excel | OpenPyXL + Pandas (قراءة/تحويل/كتابة حقيقية مع الحفاظ على تنسيق الفورمة) | `backend/excel_service.py` |
| المطابقة الذكية | محرك مدمج (قاموس مرادفات عربي/إنجليزي + تشابه نصي + قواعد محفوظة) مع دعم اختياري لنموذج ذكاء اصطناعي عبر أي واجهة OpenAI-compatible | `backend/mapping_engine.py` |
| تصدير PDF | ReportLab + arabic-reshaper + python-bidi (تشكيل عربي صحيح) | `backend/excel_service.py` |
| قاعدة البيانات | SQLite (طبقة `db.py` معزولة وقابلة للاستبدال بـ Supabase/Postgres مباشرة) | `backend/db.py` |

## التشغيل

```bash
# الخادم الخلفي (منفذ 8000)
cd backend
pip install fastapi uvicorn python-multipart pandas openpyxl reportlab arabic-reshaper python-bidi
python -m uvicorn main:app --host 0.0.0.0 --port 8000

# الواجهة (منفذ 5173، مع وكيل /api إلى الخادم)
cd frontend
npm install
npm run dev
```

## الميزات المنفذة

- **لوحة معلومات عربية RTL** مع بطاقات إحصائية ونشاط التحويل والعمليات الأخيرة.
- **معالج تحويل من ٤ خطوات**: رفع الملفات ← اختيار الفورمة ← المطابقة الذكية ← المعاينة والتصدير.
- **رفع حقيقي** لملف واحد أو عدة ملفات (سحب وإفلات)، ومعالجة عدة أوراق عمل مع تحديد صف العناوين لكل ورقة.
- **مكتبة فورمات**: إضافة/معاينة/إعادة تسمية/نسخ/حذف/تصنيف، مع حفظ ملف الفورمة الأصلي.
- **مطابقة ذكية للأعمدة**: اقتراحات مع درجة الثقة وسبب المطابقة، تعديل يدوي، تجاهل أعمدة، حفظ قواعد مطابقة تُطبق تلقائياً مستقبلاً، وتنبيه الحقول المطلوبة الناقصة.
- **معاينة النتيجة** في جدول قابل للتعديل المباشر مع التحقق من البيانات (نواقص/تكرارات/أعمدة فارغة) والاعتماد النهائي.
- **تصدير حقيقي**: XLSX (يُكتب داخل نسخة من ملف الفورمة الأصلي فيحافظ على التنسيق والعناوين المدمجة وأنماط الأعمدة)، CSV (بترميز UTF-8 BOM لسلامة العربية في Excel)، PDF (بتشكيل عربي صحيح واتجاه RTL).
- **سجل عمليات وتقارير** أداء، و**إعدادات** للغة (عربي/إنجليزي مع تبديل الاتجاه) والذكاء الاصطناعي.

## ربط الذكاء الاصطناعي (اختياري)

من صفحة **الإعدادات ← الذكاء الاصطناعي**: فعّل الخيار وأدخل مفتاح API وعنوان الخادم واسم النموذج (أي خدمة OpenAI-compatible). يُحفظ المفتاح في قاعدة بيانات الخادم ويُستخدم في الطلبات الخلفية فقط، ويُرسل للواجهة مقنَّعاً. بدون مفتاح يعمل المحرك المدمج تلقائياً.

## الاستبدال بـ Supabase

طبقة البيانات معزولة بالكامل في `backend/db.py` (كل الاستعلامات فيها). للترحيل إلى Supabase:
1. أنشئ مشروع Supabase وجداول مطابقة لمخططات `init_db()` (files, templates, operations, settings, mapping_rules).
2. استبدل دوال `db.py` باستعلامات Postgres عبر `supabase-py` مع نفس التواقيع.
3. لخزن الملفات: استبدل مسارات `storage/` برفع إلى Supabase Storage ومرر الروابط للدوال نفسها.
4. للمصادقة: أضف middleware يعتمد جلسة Supabase Auth على مسارات `/api/*`.
